# jiedian - 免费节点自动测活订阅池

本项目基于 [freesub](https://github.com/hezhanleiok/freesub) 项目进行扩展，添加了更多高质量订阅源。

## 订阅链接

### 全部节点
- **V2RayN**: https://raw.githubusercontent.com/wdongxu2022/jiedian/main/output/v2ray.txt
- **Clash**: https://raw.githubusercontent.com/wdongxu2022/jiedian/main/output/clash.yaml
- **sing-box**: https://raw.githubusercontent.com/wdongxu2022/jiedian/main/output/singbox.json

### 家宽专区（住宅IP）
- **V2RayN**: https://raw.githubusercontent.com/wdongxu2022/jiedian/main/output/residential.txt

## 使用方法

1. 打开 V2RayN 或其他客户端
2. 点击"订阅" → "添加订阅"
3. 粘贴上面的链接
4. 设置刷新间隔（建议 6 小时）

## 自动更新

GitHub Actions 每 6 小时自动运行，更新节点列表。
